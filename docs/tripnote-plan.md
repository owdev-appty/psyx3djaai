# TripNote 仕様（v1.3.1）

2026-10-13 時点の仕様です。作っている途中の計画と、版ごとに決まったことの記録は、v0.14.0 までのこのファイル（git の履歴）にあります。
個人データ（旅の中身・金額・店など）と、AI 用の Worker の中の情報（名前・設定）は、このファイルに書きません。

---

## 1. どんなアプリか

旅の準備・行程・予約・お金・持ち物・行った店・学びを、**旅ごと**と**場所ごと**にまとめる、自分用の iPhone のホーム画面アプリ（PWA）です。

- 素の HTML / CSS / JavaScript（ES Modules）。ビルドもライブラリのインストールもいらない。並べ替えだけ SortableJS 1.15.6（`vendor/`、MIT）を同梱
- GitHub Pages で公開。Service Worker でアプリの中身を端末に入れておくので、オフラインでも開ける
- いつもダークモード。フォントは M PLUS Rounded 1c（Google Fonts。端末にも入れておく）
- データは端末の中（localStorage と IndexedDB）にだけある。サーバーには送らない（AI を使ったときに、決めた内容だけを送る）
- テストは `node --test`（追加のライブラリなし）

## 3. 画面

### 下のタブ
**Trips** / **Places** / **Packing** / **Money** / **＋**（右端。Add）。右上の歯車で **Settings**。

### Trips（ホーム）
- 見出し Trips と今日の日付、右上に **＋ New trip**
- **バックアップしましょう**（条件は 5章）、ふりかえりの案内、容量の注意
- **Next trip**（あと◯日・旅行中・今日から、Spent。旅行中は **Today** に今日の予定を3件まで）、**To do**（終わっていない旅の To do の予定・todos・検討中の予約。タップでその日を開く）、**Upcoming**、**Planning**（日程未定の旅）、**過去の旅**（年ごと）
- 0件のとき「まだ旅がありません」「右上の ＋ New trip から作れます」

### 旅の画面
- 上に旅の名前・日程・状態（**Idea / Planning / Booked / Done / Cancelled**）と **Edit**。名前の下に旅の場所のボタン（`石垣島 ›`。押すと場所ノート）
- タブ **Plan / Bookings / Money / Packing / Notes**。タブと Plan の日付の列は1つの箱にまとめて、スクロールしても上に止まる（入力中は止めない）
- 最終日の翌日から Done にするまで「旅が終わりました。ふりかえりをしましょう」

**Plan**
- 日付の列（`11/3 火` と `1日目`、最後に **日程未定**）。旅行中は今日の日付に **Today** と出す。開き直したら、旅行中は今日・それ以外は Day 1。アプリを開いている間は見ていた日を覚える
- **Day notes**、時間帯ごとの予定（**朝 / 昼 / 夕方 / 夜 / いつでも**）。時刻のない予定はつまみでドラッグして並べ替え
- 予定のカード：種類のアイコン（読み上げ用の名前つき）・タイトル・状態・メモ・予約の要約・リンク・画像
- **＋ Add plan**。シート：Title（その旅の場所の店の名前を候補に出す）、Day、いつ？（決めない / 朝 / 昼 / 夕方 / 夜 / 時刻を入れる）、画像（4枚まで）、Kind（アイコン＋名前）、Status、Note、Link、予約の欄（Kind が交通・宿のとき。Booked via・From・To・No.（便名）・Price・Miles・Cancellation・Payment・予約番号・Note）
- 追加のとき、Kind が Food / Bar / Sight / Activity / Shop なら **店にも入れる**、Stay なら **宿にも入れる**（初期値オン。場所が2つ以上の旅は場所を選ぶ）。同じ名前の店があれば新しく作らずにつなぎ（「「◯◯」は店にあります。新しく作らずにつなぎます」）、なければ Want to go で入れる。店の名前を選ぶと、Kind が Other なら店の種類にそろえる。一度つないだら同期はしない（予定の名前を変えても店は変えず、予定を消しても店は残す）。店の Add to plan から入れた予定は、今までどおり Plan にだけ入る
- 同じ場所への旅では、上にたたんで「**石垣島：前回の学び**」（件数つき）。中に、前回のふりかえり（その場所の、いちばん新しい終わった旅の先頭3行）、Notes to self、店（Want to go / Go again / Next time!。状態と Add to plan は店名の下の段）、移動のコツ（押すと場所の移動のコツ）
- 種類：**Flight / Train / Bus / Ferry / Car / Stay / Food / Bar / Sight / Activity / Shop / Clothes / To do / Other**。交通・宿・食事・バーはカードに色

**Bookings**
- **Add from screenshot**（AI A）と **＋ Add booking**（予約を手で足す。シートの見出しは Add booking、Kind は Flight から）、件数 `予約済み 3 · To do 1 · 検討中 2`
- 予約のカード：日時・区間・No. / Price / Cancellation / Payment / Booked via / Note、**予約番号**（`••••`。タップで表示）、状態の切り替え（予約済み / 検討中 / To do）、**Add to Money**（Price かマイルがあるとき。Title・分類（交通 / 宿泊）・円・マイル・支払いを入れた状態で Add expense を開く。入れた後は「Money に入れました（18,000円）」（マイルだけなら `15,000 mi`）。ボタンの横に「手で Money に入れていれば不要です」。支出の `fromItemId` で予約とつなぎ、二重に入れない）
- **候補**（比べた候補。＋ 候補を追加）。欄は Title・**Price（円）**・Detail・Link。Price のある候補が2つ以上なら **安い順**。Edit に **Book this**（シートの今の Title・Detail（Note に）・Link・Price（予約の Price に）を入れた状態で予定のシートを開き、保存したときだけその候補は消える）。Bookings から作った予定は、予約の欄が空でも予約として付け、Kind に関係なく Bookings に出す。AI のスクショ取り込みの「候補に追加」も Price（円）が入る

**Money**
- 合計（円・マイル）、1泊あたり、分類ごと（交通 / 宿泊 / 食事・飲み / 土産 / 体験 / その他）
- **Expenses**（＋ Add expense）：Title・分類・金額（円か外貨7つ：VND / TWD / USD / KRW / THB / EUR / SGD）・Miles・支払い（現金・カード / マイル / 補助・クーポン、複数選べる）・概算・Note、**家計簿済**の切り替え、「家計簿 未転記 ◯件」と「すべて家計簿済にする」
- 旅だけのレート、同じ場所の **過去の旅** との比較

**Packing**
- タグのボタン（オン・オフ）、準備数と棒
- **Start from last trip**（まだタグも This trip only もないとき。同じ場所の、日程のある前のいちばん新しい旅（この旅が日程未定なら、終わった旅）の、オンのタグと This trip only を写す。チェックは付けない・同じ名前は足さない）
- **MUST!**（忘れると困る物）→ オンのタグごとの欄 → **This trip only**（この旅だけの物。行ごとに **To master**：この旅でオンのタグを付けて持ち物マスターに入れ、This trip only から外す。マスターに同じ名前の物があれば、新しく作らずにタグを足す。チェックは引き継ぐ）→ **Note**（例：タオル、ドライヤーは宿にある）

**Notes**
- **メモを貼り付け**（AI B）、**To do**（チェック）、**Memo**（チェックなしの自由なメモ。画像8枚まで、ドラッグで並べ替え）、**Unsorted**（分類できなかったメモ。**Move** で予定・Notes to self・移動のコツ・店へ）、**ふりかえり**（感想）、**候補**

**ふりかえり**（旅の画面から）
- 店（予定に入っていた場所ノートの店と、ここで足した店）に **Visited / Go again / Next time! / 行かなかった**。**＋ 行った店を足す**（Name・Place・Kind・状態。同じ名前の店があればその状態を変え、なければ足す）
- **残っていること**：Unsorted のメモ・家計簿 未転記の件数（押すと Notes / Money）
- **Notes to self** に足す（「次の自分へのメモ」）
- ふりかえり（感想）と **AIで整理**（AI D）
- **Finish** で Done

### Places（場所ノート）
- 上に検索欄（「店・メモ・予定を探す」）：店・Notes to self・移動のコツ・宿・予定・Memo・旅の名前をまとめて探す（ひらがな / カタカナ、全角 / 半角、大文字 / 小文字は同じとみなす。空白で区切ると、すべて含むもの）。予定はその日、店は店のタブをその名前で絞り込んで開く（状態・種類の絞り込みは外す）。オフラインでも使える
- 場所の一覧（行った回数・最後の年）、**＋ New place**
- 場所の画面：名前・地域・行った回数・**Edit**。タブ **Notes to self / 移動のコツ / 店 / 宿 / 過去の旅**
  - Notes to self：強調色のカード、ふりかえりから足したものは `◯◯から`、下に **Links**。**AIで整理**（AI E）
  - 移動のコツ：Title・Text・Link。**AIで整理**（AI E）
  - 店：エリアごと、検索欄（「店の名前・メモで探す」）、状態で絞り込み（**Want to go / Go again / Next time! / Visited**）、種類のアイコンで絞り込み（もう一度押すと外れる。種類が2つ以上のときだけ出し、今の店にない種類では絞り込まない）、種類（Food / Bar / Sight / Activity / Shop / Souvenir / Cowork）はアイコンだけ、地図・電話のボタン、**Add to plan**、ドラッグで並べ替え、**＋ エリア**
  - 宿：ドラッグで並べ替え
  - 過去の旅：泊数・合計・1泊あたり
- どの一覧も、つまみでドラッグして並べ替えられる

### Packing（持ち物マスター）
- 持ち物（Name・タグ・MUST!）、タグで絞り込み、ドラッグで並べ替え
- **選択** でまとめて **タグを付ける / タグを外す**（タグを複数選んで **決定**）
- **タグ**の画面（並べた順番が、旅の Packing のボタンの順番）

### Money（すべての旅）
- **By year**（年ごとの合計）、**By place**（`4回・29泊（計算に使用 22泊）・合計448,314円 ／ 1泊 20,378円`。1泊はお金が登録されている旅だけで計算）

### ＋（Add）
入れる旅を選んで、**Quick memo**（AI なし・オフラインでも使える。Save で選んだ旅の Notes の Memo に入る。書きかけはほかのタブに移っても残る）、その下に **AI** の **Add from screenshot** / **メモを貼り付け**。

### Settings
- **Backup**：Last backup、**画像も含める**（初期値オン。画像があるときだけ出す）、書き出す前に「ファイルの大きさ：約35MB（画像100枚を含む）」、**Export backup** / **Restore from backup** / **Undo restore**
- **Currency rates**（1円あたりの外貨。旅ごとにも変えられる）
- **AI**：AI を使う、合言葉（伏せ字・表示 / 隠す）、今日の残り回数と **更新**、送るものの説明
- **Data**：件数・画像・容量・保存の保護
- いちばん下にアイコンと版

## 4. 表記のきまり
- 見出し・ボタン・ラベルは基本は英語（Trips / Places / Packing / Money、Plan / Bookings / Notes、Day notes、Want to go / Go again / Next time! / Visited、Notes to self、Add from screenshot、Save / Cancel / Delete / Edit / Add、To do）
- 日本語のままのもの：朝 / 昼 / 夕方 / 夜 / いつでも、移動のコツ / 店 / 宿 / 過去の旅、持ち物マスター / タグ、現金・カード / マイル / 補助・クーポン / 家計簿済、ふりかえり、予約済み / 検討中、ほかに作りながら決めた日本語の表記（メモを貼り付け、AIで整理、候補、＋ 候補を追加、＋ エリア、MUST! など）
- 入力のヒントや補足は短い日本語。削除の確認はいつも `Delete "◯◯"?` と `This can't be undone.`
- 0件のときは、次に何をすればよいかも書く（例「右上の ＋ New trip から作れます」）

## 5. データ

| 項目 | 内容 |
|---|---|
| 保存場所 | localStorage の `tripnote.v1`（バックアップと同じ形の JSON。schemaVersion 1）。画像は IndexedDB `tripnote-images`（長い辺1600px の JPEG と 320px の小さい画像） |
| ほかのキー | `tripnote.secret`（AI の合言葉）、`tripnote.ui`（画面の状態・最後に書き出した日時・データが変わった日時・お知らせを隠した日）、`tripnote.v1.prev`（復元を取り消すための前のデータ）。この3つはバックアップに入れない |
| 読み込み | 足りない項目や null は初期値で補い、知らない項目は消さずに残す。古い形（支払いが文字1つ、以前の機能の項目など）も読める。読めなかったときは上書きせず、中身をそのまま書き出せる |
| 保存 | 変更の約0.3秒後にまとめて保存。容量の80%で注意、95%で強い警告（目安5MB） |
| 書き出し | `tripnote-backup-YYYY-MM-DD.json`。iPhone では共有メニューから「ファイル」へ。初期値は画像も含める（画像は base64 で JSON に入る）。書き出す前にだいたいの大きさを出す |
| 復元 | 形式チェック → 中身の要約 → `Replace all data?` → 置き換え。前のデータを1つだけ残し **Undo restore**。保存できなければ前のまま |
| 画像の片付け | 予定・Memo・旅を消しても画像はすぐ消さず、次に開いたとき、今のデータと前のデータのどちらも使っていない画像だけを消す |
| リンク | http / https だけ（javascript: などは表示も保存もしない） |
| 消えにくくする | 起動のときに `navigator.storage.persist()` を呼ぶ（結果は Settings） |
| バックアップしましょう | 最後に書き出してから7日以上たっていて、その後にデータが変わっていたら、Trips の上に出す。押すと大きさを見せてから書き出す。×でその日は出さない |
| 予約番号 | `booking.referenceNo`。画面では `••••`。AI には送らないし、AI の結果からも入れない |
| v1.1.0 からの項目 | `candidates[].priceYen`（候補の Price）、`expenses[].fromItemId`（Add to Money で入れた支出と予約のつながり）、`spots[].fromTripId`（ふりかえりで足した店）。どれもデータの版（schemaVersion 1）は変えず、知らない項目として読み込み・バックアップ・復元で残る |

## 6. AI（すべて「確認してから保存」）

- AI 用の Worker を、合言葉（`X-TripNote-Token`）をつけて呼ぶ。Worker は Origin・合言葉・1日20回までの回数・大きさを確かめ、task ごとに決めた指示と出力の形（JSON スキーマ）とモデル（Claude Sonnet 5.5）を使う。アプリから指示文やモデル名は送れない
- 実行する前に「回数を1回使います（今日の残り◯回）」。オフラインなら押した時点で「オフラインです」。AI は120秒・今日の残りは10秒で時間切れ。失敗しても入力した内容は消さない
- 送る前に、メールアドレス・電話番号・カード番号・予約番号・会員番号・パスポート・生年月日を伏せ字にする。AI の結果にそれらが入っていても取り除く。予約番号の欄と、予定に添付した画像は送らない
- 確認画面の保存ボタンは **Save**

| | どこから | 送るもの | 返すもの・保存 |
|---|---|---|---|
| A. Add from screenshot | Bookings、＋ | 予約画面のスクショ3枚まで（長い辺1600px に縮小。保存しない）、旅の名前・日程・行き先 | 予約ごとに直してから、予約済み / 検討中の予定（＋予約の欄）か候補に。外貨はレートで円に |
| B. メモを貼り付け | Notes、＋ | 貼ったメモ（8,000文字まで。長いときは分けて貼る） | 予定 / 予約 / 持ち物 / To do / Memo / Unsorted に振り分けた案を、1件ずつ選んで保存 |
| D. ふりかえり整理 | ふりかえりの **AIで整理** | ふりかえりの文と答え、旅の場所の名前、ふりかえりの店（予定に入っていた店と、ふりかえりで足した・答えた店）の名前と状態（記号で送る） | 店の状態・店のメモ・Notes to self（「◯◯から」）の案を、採用・却下・修正 |
| E. 場所ノートの整理 | 場所の Notes to self・移動のコツの **AIで整理** | その場所の Notes to self と移動のコツの全件（記号で送る） | まとめる（元の項目は消えて、元の位置に1件）・古くなっていそう（消す）・上に置く の案を、変更前と変更後を並べて採用・却下 |

## 7. アプリの更新とオフライン
- アプリの中身（HTML・CSS・JS・アイコン・フォント）は Service Worker が端末に入れておく。機内モードでも、開く・見る・追加・編集ができる
- 起動したときと、アプリに戻ってきたときに新しい版を確かめる。準備ができたら下に「新しい版があります」と **今すぐ切り替える**（入力中・シートを開いている間は出さない。勝手に読み込み直さない）。切り替わったら「v◯ になりました」

## 9. iPhone で気をつけていること
- 入力欄は16px以上（自動で拡大されないように）。日本語の変換中は保存したり欄を動かしたりしない。変換を確定する Enter（keyCode 229）では追加しない
- シートは、見えている範囲（visualViewport）に合わせる。開いたときの入力欄への focus は、シートが開き終わってから
- ステータスバー・ノッチ・ホームバーの safe-area に合わせる。押すものは44px以上
