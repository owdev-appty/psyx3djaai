# TripNote

旅の準備・行程・予約・お金・持ち物・行った店・学びを、**旅ごと**と**場所ごと**にまとめる、自分用の iPhone アプリ（PWA）です。
iPhone の Safari で開いて「ホーム画面に追加」すると、アプリのように使えます。オフラインでも開けます。

## できること

- **Trips**：旅ごとに、日ごとの予定（Plan）・予約（Bookings）・お金（Money）・持ち物（Packing）・メモ（Notes）
- **Places**：場所ごとに、次の自分へのメモ（Notes to self）・移動のコツ・店・宿・過去の旅
- **Packing**：持ち物マスターとタグ。旅ごとにタグを選ぶと持ち物リストができる
- **Money**：年ごと・場所ごとのまとめ（1泊あたりの比較）
- **ふりかえり**：旅が終わったら、店の状態と次の自分へのメモを残す
- **AI（使うときだけ）**：予約画面のスクショの取り込み、メモの振り分け、ふりかえりの整理、場所ノートの整理。結果は必ず確認画面で直してから保存します

## 使い方の流れ

1. **＋ New trip** で旅を作り、行き先の場所を選ぶ
2. 準備：Plan に予定、Bookings に予約、Packing でタグを選んで持ち物を確認
3. 旅行中：Plan とメモを見ながら、使ったお金を Money に足す（オフラインでも使えます）
4. 旅のあと：ふりかえりで店の状態と次の自分へのメモを残し、Finish
5. 次に同じ場所へ行くとき：前回のメモと「Want to go / Next time!」の店が、旅の Plan の上に出ます

## データについて

- データは **iPhone の中（このアプリの保存領域）にだけ** あります。サーバーには保存しません
- AI を使ったときだけ、その機能に必要な内容を送ります。メールアドレス・電話番号・予約番号などは伏せ字にしてから送り、予約番号の欄と添付した画像は送りません
- Safari の「履歴と Web サイトデータを消去」や、ホーム画面のアイコンの削除で、データは消えます

## バックアップのすすめ

- **Settings → Backup → Export backup** で、すべてのデータを1つのファイルに書き出せます（初期値は画像も含める）。iPhone では共有メニューから「ファイル」の iCloud Drive に保存するのがおすすめです
- 7日以上書き出していなくて、その後にデータが変わっていると、Trips の上に「バックアップしましょう」と出ます
- 戻すときは **Restore from backup**。戻す前のデータに戻したいときは **Undo restore**
